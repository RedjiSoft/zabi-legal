# User Agreement for Zabi

**Last updated: September 29, 2026**

## 1. Introduction

This User Agreement applies to the Android application Zabi ("Зъби").

Zabi is a personal reminder application designed to help users maintain a regular tooth-brushing routine and manage related reminders.

By using the application, the user agrees to the terms described below.

## 2. Application Functions

Zabi may provide functions including:

- morning and evening tooth-brushing reminders;
- personal brushing history;
- dentist appointment reminders;
- configurable reminder times and delays;
- optional integration with Huawei Health Service Kit for sleep-based morning reminders.

Features may be changed, added, or removed as the application is developed.

## 3. Huawei Health Integration

With the user's explicit authorization, Zabi may obtain read-only access to sleep data through Huawei Health Service Kit.

Sleep information is used only to determine when the user's sleep period has ended so that the application can schedule a morning tooth-brushing reminder after the delay selected by the user.

Authorization is optional. The user may deny or revoke access to Huawei Health data.

Zabi does not modify or delete Huawei Health data.

## 4. User Control and Permissions

The user is responsible for selecting reminder settings and granting or denying permissions requested by the application.

Some features may not function when the permissions required for those features are disabled.

Users should consult an appropriate healthcare professional regarding medical or dental concerns.
